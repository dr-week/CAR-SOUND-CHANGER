## 🔄 Documentation Updates

### How to Update Documentation

1. **Found outdated info?**
   - Create issue with "docs" label
   - Specify which document and what needs updating

2. **Want to add documentation?**
   - Follow [CONTRIBUTING.md](../CONTRIBUTING.md)
   - Use existing docs as templates
   - Link to related documents

3. **Documentation standards:**
   - Use Markdown format
   - Include code examples
   - Add cross-references
   - Keep it updated with code changes

### Documentation Review Cycle

- **Weekly**: Update TASKS.md with progress
- **Per Feature**: Update technical docs when feature is complete
- **Per Release**: Review and update all documentation
- **Continuous**: Fix errors as they're discovered
