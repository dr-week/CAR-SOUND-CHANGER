# Tutorial: Car Sound Changer Setup

This tutorial walks you through setting up and using the Car Sound Changer app.

## Step 1: Installation
Read [INSTALLATION.md](docs/INSTALLATION.md) for setup instructions.

## Step 2: First Launch
Run `npm run build:android` to generate the APK.
Launch the APK on an Android device with API level 24+.

## Step 3: Usage Basics
- GPS integration provides real-time speed data
- Engine sounds sync with vehicle velocity and gear changes
- Bluetooth supports audio routing

## Step 4: Troubleshooting
Check [TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) for common issues.
