# Quick Start Guide

Get up and running quickly with the Car Sound Changer Android app.

## Installation:
1. Follow [INSTALLATION.md](docs/INSTALLATION.md) for setup
2. Run npm install to install dependencies
3. Execute `npm run build:android` to compile the app

## Getting Started:
```bash
cd carSOUNDMOD
npm install
npm run build:android
```

The app will automatically detect GPS and audio permissions.
